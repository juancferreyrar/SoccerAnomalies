# SoccerAnomalies : Detecting Statistical Anomalies in Soccer Players Through Multivariate Normal Distribution
## Objective
Our objective is to identify soccer players whose statistical performance differs significantly from other players in a similar field position.

## Data sources
Kaggle - [Football Players Stats (2025-2026)](https://www.kaggle.com/datasets/hubertsidorowicz/football-players-stats-2025-2026)

## Directory Structure
src/data_load.ipynb - The simulation and real-data loading script

docs/ProjectPlan.csv - Project Plan with the task table
